# **Tic-tac-toe**

**Version 1.0.0**

<br>

[**Tic-tac-toe**](https://en.wikipedia.org/wiki/Tic-tac-toe) is a basic paper-and-pencil game for two players who take turns marking the spaces in a three-by-three grid with X or O. 

Since most programmers are said to be less social, it is difficult for us to find people to play Tic-tac-toe with. That is the reason I made Venice, an A.I. utilizing the [Minimax algorithm](https://en.wikipedia.org/wiki/Minimax) with the sole purpose of beating every being in existence in a game of Tic-tac-toe.

## **Requirements:**
- Python 3.x
- pygame

## **How to Use:**
- Run _scr/main.py_.
